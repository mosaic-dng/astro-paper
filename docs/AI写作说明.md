# 给 AI 的文章写作说明

复制下面的文字，替换方括号中的内容后交给 AI：

请为我的 AstroPaper 博客写一篇 Markdown 文章，主题是：[主题]。
面向读者：[读者]。
语气：[语气]。
请保留我提供的事实与链接参数，不编造价格、体验、测试结果或来源。
输出完整 .md 内容和建议的小写英文文件名，不要把整篇文章包在代码块中。
顶部必须使用以下 YAML 字段：
title、description、pubDatetime（ISO 日期，时区 +08:00）、category、tags、featured: false、draft: false。
不要填写与当前模板无关的 slug 字段；文章网址由文件名决定。
正文使用标准 Markdown 的标题、列表、表格、引用和代码块。正文从二级标题开始，顶部标题会由网站显示。
图片使用相对路径 ./建议文件名.assets/图片名.png，并附一份需要准备的图片列表。
不要使用电脑绝对路径、Notion 临时图片链接、脚本或复杂 MDX 组件。
文章最后列出真实的参考链接，不要捏造引用。
完成后我会用 Typora 修改，再从 GitHub 网页上传。
